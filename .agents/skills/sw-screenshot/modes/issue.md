# Mode: issue

One shop on **trunk**, one set of screenshots.

## The target

The state the reporter describes — usually the defect itself: the misaligned element, the missing
button, the wrong total. If several symptoms are described, pick the one a picture conveys best.
Name the single page that would show it, reach that, photograph it. One image, unless a second
shows something the first cannot.

## Trunk is not the reported version

The issue may cite an older release; the shop runs trunk regardless. A healthy page is then a real
result: post it and say in one sentence that the symptom was not observed. Never caption it as the
bug.
