# Core
* The installer now supports presets based on the selected language. This allows for a more tailored installation experience, where the default settings and configurations can be adjusted according to the language chosen by the user during the installation process.
* The installer has been updated to have the language selection always available as a selection in the header instead of the previous text-based links in the footer. This change enhances usability by making language selection more prominent and accessible throughout the installation process.
