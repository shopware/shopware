Done criteria

The generator prototype is done when all of these pass:

  • All known breaks of the historical cases are reported, and #17081 has no finding.
  • Renaming a block, a method and a prop that the Storefront bundle uses fails the check each time.
  • Two runs on the same commit produce byte-identical output.
  • A PR that only regenerates the snapshot still fails the break check.
  • Fewer than 5% false alarms on about 50 merged Administration PRs, judged together with an Administration lead.
