Everything without @private is public.

The rule is already documented. The snapshot makes it checkable.

  1. Sourcecomponents, Twig, modules, en.json
  2. Generatorcomposer admin:generate-public-api
  3. public-api/committed .api.md and .d.ts files
  4. CIcompares base and head, fails on breaks nobody announced
  5. Pluginstypes and a compatibility check
