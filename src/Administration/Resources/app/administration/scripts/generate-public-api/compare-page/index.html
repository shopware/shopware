Administration public API check

Compares two states of the Administration and lists what changed for plugins: breaks, new public API, announced changes. The check runs in your browser on sources it loads from GitHub.

or
GitHub token, optional

GitHub allows 60 requests per hour without a login, and a comparison takes two to four. A token lifts that limit. It stays in this tab and is only sent to api.github.com.

Computed with the generator of commit %GENERATOR%. A pull request is compared with the commit it branched off its base branch. The check in the pipeline decides whether a pull request may merge.
