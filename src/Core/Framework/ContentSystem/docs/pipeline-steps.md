# Pipeline Steps

The diagram is in [data-flow.md](data-flow.md).

- `ContentPipeline::load()`: receives the loaded stored [forest](principles/README.md#glossary) → `ContentTreePreparationEvent` → stored preparation (`Layout/Scaffolding/StoredTreePreparer::prepare()`: placeholder substitution in FULL mode only, then the [virtual root](principles/README.md#glossary) wrap via `Layout/Scaffolding/VirtualRootWrapper`, then the [partial prune](principles/README.md#glossary) via `Output/PartialRenderer`, all still stored) → duplicate-element-id rejection on the forest before the partial prune → `Rendering/WiringPlanner::plan()` (wiring validation on that same forest, then derived providers on the forest after the partial prune) → the render step (`Rendering/ElementLowering::lower()`: forest-wide data resolution, the once-per-render root context resolution of the specification's page-level data requirements against the virtual root the pipeline hands it from the forest before the partial prune, context-delivery resolution, rendered-tree creation; FULL mode does all four, SKELETON mode creates structure only) → the [finishing steps](principles/README.md#glossary), on the rendered forest (`VirtualRootWrapper::unwrap()`, then `PartialRenderer::extractTarget()`, both driven by the `RenderScaffolding`) → `RenderedTreeFinalizationEvent` over the rendered forest, in both modes → duplicate-element-id rejection again, over the forest the event handed back. Both checks throw `DUPLICATE_ELEMENT_ID` (500, not a client defect) in either mode. The pipeline takes both format answers from the route: the `RenderingMode` and whether the format collects a value index
- Inside `Rendering/WiringPlanner::plan()`, wiring validation judges the forest before the partial prune and derived providers are created on the forest after it, throwing nothing: [the render validates the whole stored forest](principles/rendering.md#the-render-validates-the-whole-stored-forest-in-every-mode)
- Specification resolution and layout-entity loading happen in `ContentRoute`, NOT in `ContentPipeline`
